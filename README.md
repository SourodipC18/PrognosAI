# 🤖 PrognosAI
**Predictive Intelligence for Maintenance**

> PrognosAI is a hybrid CNN–LSTM deep learning system designed for predictive maintenance.  
> It leverages Explainable AI (SHAP) to provide transparent insights into machine failure predictions,  
> helping industries move from reactive to proactive maintenance.

---

### 🚀 Features
- Hybrid CNN + LSTM architecture for time-series prediction  
- Explainable AI (XAI) integration using SHAP  
- Visual insights on feature importance and failure causes  
- Built on the Microsoft Azure Predictive Maintenance dataset
